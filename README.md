# オフライン共有データベース（ミニ kintone）

Flask と SQLite を使った、オフラインで利用できるシンプルな共有データベースです。ネットワーク接続がない環境でも動作し、複数人で同じ端末を共有したり、ローカルネットワーク内で同じアプリを使ってデータを更新できます。

## 特徴

- SQLite に保存するためネットワーク不要
- レコードの追加・編集・削除に対応
- 直感的に操作できる簡易的な UI
- Python と Flask があればどの OS でも動作

## セットアップ

1. Python 3.10 以上をインストールします。
2. 必要なパッケージをインストールします。

   ```bash
   pip install -r requirements.txt
   ```

3. アプリケーションを起動します。

   ```bash
   python app.py
   ```

4. ブラウザで [http://localhost:5000](http://localhost:5000) を開きます。

初回起動時に `data.sqlite` が自動的に作成され、同じフォルダにデータが保存されます。別の端末と共有したい場合は、このファイルを共有フォルダに置くか、同じアプリケーションをその端末で起動してください。

## 画面構成

- 一覧画面：登録されたレコードを閲覧し、編集・削除できます。
- 編集画面：タイトルと詳細を入力して保存できます。

## データのバックアップ

- アプリを停止した状態で `data.sqlite` ファイルをコピーするだけでバックアップできます。
- 定期的にバックアップを取得し、別の場所に保管することをおすすめします。
