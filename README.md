# Cyber Neon Playground

未来都市のナイトライフをテーマにしたインタラクティブWEBアプリです。ブラウザで `index.html` を開くだけで、以下のギミックを体験できます。

## 主なコンテンツ
- 🌠 **スターライト背景**: キャンバス上で星々が飛び交うスペーストンネルを演出。
- 🚀 **ハイパードライブ起動**: 「ENTER THE HYPERSPACE」ボタンで背景が一瞬で加速モードに。
- 🎯 **ミッションジェネレーター**: 未来都市で挑戦するクエストをランダム生成。
- 🎹 **シンセビートループ**: 3トラック×8ステップの簡易シーケンサー。クリックで音を並べ、PLAYで再生。
- 🔮 **ムードオーラ**: 気分を選ぶと、カードのオーラとメッセージが変化。
- 🖥️ **ネオンターミナル**: hack / vibe / boost などのコマンドでAIレスポンスを楽しめます。

## 使い方
1. リポジトリをクローン。
2. `index.html` をブラウザで開く。
3. サイバーパンクな世界観とインタラクションを楽しむだけ！

音声を再生するにはブラウザでのユーザー操作が必要です。ボタンを押してからビートが鳴り始めるまで少しタイミングをお楽しみください。
