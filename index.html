ごみ収集カレンダー

Googleスプレッドシートを更新するだけで運用できる、ごみ収集スケジュール管理アプリです。自治体ごとのデータを読み込み、地域・品目ごとの収集予定を確認できます。

導入方法を見る

地域を選択

スプレッドシートに登録されている自治体と地区から選択してください。選択内容に応じて収集スケジュールが自動的に切り替わります。

直近の収集予定

次に訪れる収集日を最大10件まで表示します。予定をそのままカレンダーに追加できるiCalendarファイルを生成することも可能です。

該当する収集予定が見つかりません。フィルターを調整してください。

品目凡例

品目ごとに色・説明文を設定できます。スプレッドシートを更新すると自動で反映されます。

    導入手順

    自治体ごとのスプレッドシートを更新することで、開発者以外でも簡単に運用できます。

    1. テンプレートスプレッドシートを複製 — Googleスプレッドシートに municipalities / areas / categories / collection_schedule の各シートを作成し、自治体の情報を入力します。
    2. 自治体・地区を追加 — municipality_id と area_id をユニークなIDとして設定し、地区名称や説明を入力します。
    3. 収集スケジュールを記入 — collection_schedule シートに日付（YYYY-MM-DD形式）、品目ID、注意事項を入力します。
    4. 公開設定を変更 — スプレッドシートを「リンクを知っている全員が閲覧可」にし、シェア用URLからスプレッドシートIDを確認します。
    5. 利用開始 — app.js の CONFIG.googleSheets.spreadsheetId にIDを設定すると、最新のスケジュールが自動的に読み込まれます。

    Googleスプレッドシートにアクセスできない場合は、自動的に data フォルダのCSVへフォールバックします。ローカルで検証したい場合に活用してください。
