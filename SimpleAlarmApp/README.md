# SimpleAlarmApp

物凄いシンプルな目覚ましアプリです。`TimePicker` で時刻を選び、「アラームを設定」ボタンを押すだけで次のアラームが予約されます。設定時刻になると端末のデフォルトアラーム音が鳴り、停止ボタンで止められます。

## 主な機能
- 24時間表記のタイムピッカーで時刻設定
- 端末がスリープ状態でも `AlarmManager` による正確なアラーム発火
- 次のアラーム時刻を画面で表示
- アラーム発火時には専用の全画面に近い画面を表示し、サウンドを鳴らす

## ビルド方法
1. [Android Studio](https://developer.android.com/studio) をインストールします。
2. `File` -> `Open...` からこの `SimpleAlarmApp` ディレクトリを開きます。
3. Gradle の同期が完了したら、接続した実機またはエミュレータで `Run` を実行します。

## 注意点
- 最低動作バージョンは Android 7.0 (API 24) です。
- 省電力機能が非常に強力な端末ではアラームの正確性が低下する可能性があります。その場合は端末の設定でアプリをバッテリー最適化の対象外にしてください。
